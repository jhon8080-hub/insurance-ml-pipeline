# Insurance ML Pipeline

Предсказание медицинских страховых расходов (датасет insurance.csv)

## Задача
Предсказать индивидуальные медицинские расходы (`charges`) на основе демографических и медицинских характеристик: возраст, пол, ИМТ, количество детей, статус курения, регион проживания.

## Модели
- Linear Regression
- Decision Tree
- CatBoost
- XGBoost
- Neural Network (MLP)

## Результаты

| Модель | R² (test) | MAE (долл.) | Переобучение |
|---|---|---|---|
| Linear Regression | 0.7250 | $4,326 | 0.0493 |
| Decision Tree | 0.8328 | $2,741 | 0.0680 |
| XGBoost | 0.8242 | $2,982 | 0.1351 |
| **CatBoost** | **0.8383** | **$2,646** | **0.0638** |
| Neural Network (MLP) | 0.8187 | $2,942 | 0.0774 |

**Лучшая модель:** CatBoost с R² = 0.8383 и средней ошибкой $2,646
