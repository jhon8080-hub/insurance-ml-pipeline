# Insurance ML Pipeline

Предсказание медицинских страховых расходов (датасет insurance.csv)

## Задача
Предсказать индивидуальные медицинские расходы (`charges`) на основе демографических и медицинских характеристик: возраст, пол, ИМТ, количество детей, статус курения, регион проживания.

## Модели
- Linear Regression
- Decision Tree
- CatBoost
- XGBoost
- Neural Network (MLP)

## Результаты

| Модель | R² (test) | MAE | Переобучение |
|--------|-----------|-----|---------------|
| Linear Regression | 0.6795 | $4,354 | 0.0923 |
| Decision Tree | 0.7839 | $2,868 | 0.1121 |
| XGBoost | 0.7883 | $3,021 | 0.1719 |
| CatBoost | 0.8015 | $2,711 | 0.1077 |
| **Neural Network (MLP)** | **0.8187** | **$2,942** | **0.0636** |

**Лучшая модель:** Нейронная сеть MLP с R² = 0.8187 и средней ошибкой $2,942
